OVERVIEW: List all projects.

The list is in sidebar order: a project, then the projects in it. On a
terminal, the list shows as a tree. To a pipe, each project is one line, with
the name of its parent ("-" at the top level).

USAGE: macterm project list [--socket <socket>] [--json]

OPTIONS:
  --socket <socket>       Control socket path. It overrides discovery.
  --json                  Print the raw JSON payload instead of a table.
  -h, --help              Show help information.
